# CROfy

Marketing site for **CROfy**, conversion research for D2C brands: read a live store, find where shoppers leave, and name the first fix.

**Live:** https://crofy.vercel.app

## Stack

Static HTML/CSS, deployed on Vercel (`vercel.json`). Includes `robots.txt`, `sitemap.xml` and Open Graph assets.

## Run locally

```bash
npx serve .
```

## Notes

The `.claude/` folder contains SEO agents and skills from [claude-seo](https://github.com/AgriciDaniel/claude-seo) (MIT, by AgriciDaniel), used for auditing this site. They are not part of the site itself.
